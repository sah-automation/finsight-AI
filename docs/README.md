# Documentation

Project documentation.

**Belongs here:**
- Architecture decision records (`adr/`)
- Glossary (`GLOSSARY.md` at repo root)
- API reference (auto-generated from code)
- Deployment guide
- Developer onboarding
- Config switch guide (`finsight_config_switches.md`)
- Known risks (`finsight_known_risks.md`)
- High-level design diagram

**Rules:**
- ADRs for significant decisions (template in `adr/template.md`)
- Keep in sync with code - outdated docs are worse than none
- Diagrams as code (Mermaid/PlantUML) where possible
